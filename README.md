# TargetGym

This repository contains our attempts to handle the control problems available in the [`target-gym`](https://github.com/YannBerthelot/TargetGym) package.
These methods are *Monte Carlo Tree Search* variants developed for continuous search spaces [1], which, for now, are divided into two groups:

* **Full planners**: plan the full sequence of the control problem using the algorithm:
	* Gaussian Continuous Nested Rollout Policy Adaptation (GcNRPA)
	* Gaussian Continuous Generalized Nested Rollout Policy Adaptation (GcGNRPA)
	* Continuous Nested Monte Carlo Search (cNMCS)
	* Continuous Reward-based Nested Monte Carlo Search (cRbNMCS) 
* **Residual planners**: in addition to a baseline (the PID provided by the package for each problem), the algorithm aims at predicting a residual to the action given by said baseline, which results in: 
$$a = PID(observation) + \pi(observation)$$
The goal is to diminish the gap between the *required* action and the one generated by PID in order to maximize the total reward. Algorithms used for now:
	* Gaussian Continuous Nested Rollout Policy Adaptation
